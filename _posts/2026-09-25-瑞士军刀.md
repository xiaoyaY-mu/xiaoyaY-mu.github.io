# BugKu CTF Writeup-瑞士军刀

## 题目类型

PWN

## 解题思路

本题是入门PWN题，需要通过网络连接到远程Linux靶机，使用基础Linux命令浏览目录，读取flag文件。
Windows终端自带的ncat连接靶机时，回车会发送 \r\n 双换行符；而Linux只识别 \n ，多余 \r 会附加到命令末尾，导致命令执行失败。因此改用Python socket脚本，手动发送仅带 \n 的命令，规避换行符兼容问题。

## 解题过程

1. 编写Python socket脚本，填入题目给出的靶机IP与端口，建立socket连接。脚本实现接收用户输入，向靶机发送命令（仅追加 \n 换行），接收并打印靶机返回数据。

python
  
import socket

ip = "160.202.254.160"
port = 14179

s = socket.socket()
s.connect((ip, port))

while True:
    cmd = input("> ")
    s.sendall((cmd + "\n").encode())
    result = s.recv(4096).decode()
    print(result)
 

2. 将脚本保存至桌面，打开PowerShell，切换工作目录到桌面： cd Desktop 
3. 执行脚本： python bugku.py ，成功连接靶机，出现输入提示符 > 
4. 输入 ls 列出当前目录文件，返回 bin dev flag lib lib32 lib64 pwn1 ，发现flag文件。
5. 输入 cat flag 读取flag文件内容，复制输出字符串，提交至Bugku平台。

## 笔记

本次实验学习了socket套接字编程以及nc远程连接原理。Windows和Linux换行符标准不一致，在使用ncat连接Linux靶机时容易出现命令无法识别的问题。通过Python手动控制发送的换行符，可以解决跨平台换行符兼容问题，成功执行Linux命令拿到flag。
