## 题目类型
Crypto

## 解题过程
下载附件解压，得到两个文件：`flag.py`（出题人加密脚本，也叫decode.py） 和 `output`。
打开decode.py源码，可以看懂逻辑：将flag明文逐个字符分别计算MD5，把每一个字符对应的MD5密文保存到output文件中。
output文件里面，每一行字符串，都对应单个字符的MD5哈希值。

MD5是单向哈希，无法直接反向解密。但是本题明文空间极小,可以预先计算所有可打印字符的MD5值，建立「MD5密文 → 原字符」的映射字典，读取output中的每一行MD5，查表还原字符，拼接得到完整flag。

编写解密脚本
```python
import hashlib
import string

# 建立哈希到字符的映射表
hash_dict = {}
for ch in string.printable:
    h = hashlib.md5(ch.encode()).hexdigest()
    hash_dict[h] = ch

# 读取output中的md5列表，查表还原
result = ""
with open("output","r") as f:
    lines = f.readlines()
    for line in lines:
        line = line.strip()
        if line in hash_dict:
            result += hash_dict[line]

print("flag =", result)
