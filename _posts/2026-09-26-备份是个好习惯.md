## 题目类型

WEB

## 原理分析

打开页面，页面输出两段相同的MD5串，没有flag。
题目名字提示：备份文件。程序员写代码时经常会生成 .bak 备份文件，如果没有删除，就可以直接下载源码。
访问  index.php.bak  下载PHP源码

 需要先看懂这份源码
php
  
$str = str_replace('key','',$str); // 把URL参数里所有 "key" 直接删掉
parse_str($str); // 将处理后的字符串解析成变量
if(md5($key1) == md5($key2) && $key1 !== $key2){
    echo $flag,"取得flag";
}
条件：
1.  md5($key1) == md5($key2)  md5值相等（弱相等）
2.  $key1 !== $key2  两个变量完全不相同（强不等）
陷阱： str_replace('key','',$str) ，只要参数里写 key1 ，里面的 key 会被直接清空，参数就变成 1 ，变量失效！
绕过方法：双写key， kekeyy1 ，删除中间 key 之后，剩下 key1 。
Payload：?kekeyy1[]=1&kekeyy2[]=2
原理：
 
-  kekeyy1  → 删掉中间 key  →  key1 
-  kekeyy2  → 删掉中间 key  →  key2 
-  key1[]=1 ，传入数组。PHP的 md5() 不能处理数组，返回 null 
-  null == null ，满足md5相等； $key1 和 $key2 是两个不同数组， !== 成立。

## 解题过程
1. 访问靶机地址加上备份文件名index.php.bak ，下载源码审计。
2. 构造Payload：?kekeyy1[]=a&kekeyy2[]=b
3. 将payload拼接到URL，访问页面，拿到flag

## 笔记

什么是payload？
Payload就是我们用来攻击、触发题目漏洞的一段指令/参数。
在CTF里，就是你传给服务器，让它执行我们想要逻辑的内容。
这道题的payload：
?kekeyy1[]=1&kekeyy2[]=2
 含义拆解：
1.  ? ：URL里面，问号后面全部都是传给页面的参数
2.  kekeyy1[]=1 ：参数1
3.  & ：用来分隔多个参数
4.  kekeyy2[]=2 ：参数2
为什么这么写？
代码有一行： str_replace('key','',$str); 
它会把所有 key 直接删掉。
如果写 key1 ， key 被删掉，只剩 1 ，变量就没了。
写 kekeyy1 ：里面包含 key ，删除中间 key ， kekeyy1  →  key1 ，成功生成变量 key1 
同理 kekeyy2  →  key2 
 [] 代表传入数组。PHP中 md5(数组) 会返回 null 
md5($key1)=null ， md5($key2)=null ，满足 null == null 
 $key1 和 $key2 是两个不同数组，满足 $key1 !== $key2 ，两个条件全部成立，输出flag
